## Atomic notes

I make atomic notes. 

One note is one entity and one entity only — an idea, an essay, an argument. A note is the smallest, atomic, indivisible unit of my knowledge system. 

Atomic notes can be linked. 

## Special notes

Special notes in the root level include:

### Capture

`Capture` is the entry point for all ideas and inspirations, logged chronologically and separated by `---` dividers.

Periodically, I make sure to clear the page by developing the snippets into full notes. 

It's pinned in my right sidebar for quick access during work, and serves as a visual reminder to process its contents.

### TODO

For most action items I use Notion to track and execute. 

For bigger, longer tasks, I note them down here for someday in the future. 

### Claude.md

This file explains to Claude Code basics of my vault and gives important rules. 

Nevertheless, I still haven't found any really good use cases for Claude Code to become an integral part of my workflow. 

## Folder Structure

I use a one-level folder structure. 

```
├── Assets
├── Books
├── Clippings
├── Daily
├── Literature
├── Other
├── Personal
└── Publish
```

Notes that I took from reading books and internet resources go to `Literature`. 
Personal reflections, inspirations, and ideas go to `Personal`. 
Writings like essays, blogs, and newsletters go to `Publish`.

Newly created notes, regardless of their type, land in the root folder, waiting to be finished, developed, and finally sorted into the right place. The root folder is like a RAM-like workspace for active, in-progress notes. Once sorted into a folder, a note is considered complete and can be safely forgotten.

## I/O

Random ideas are captured via an iPhone shortcut triggered by the Action Button, feeding directly into **Capture**.

I use Obsidian web clipper to clip good web sources (articles, Youtube video, etc.) as pages in the root folder to read later. 

I used to use Obsidian publish to share all of my literature notes, but since June 2026 I have built my own system to self-manage this process to host all the pages to jimmyzhang.org/note (individual notes can only be accessed through their associated book or clipping page)

I publish essays in Publish to jimmyzhang.org/writing and jimmyzhang.org/newsletter

For quick one-off sharing, I use a plugin called Just Share Please to instantly share a note as a webpage — though I am exploring self-hosted alternatives. 

## Core Plugins

These are the core AI plugins I use, especially for my right sidebar. 

### Copilot

I use Copilot by Logan Yang to quickly chat with an AI model about my current note or for random questions. I also have a few pre-written slash-commands (prompts) that I can trigger easily. 

### Custom Frames

I use Custom Frames to open Google AI Studio as a webpage in my sidebar. While I can directly access Claude, GPT, and Gemini models through API in Copilot, Google AI Studio gives me the unique value of being able to process large context and entire pdfs or book documents. 

### Claude Sidebar / Terminal

I use Claude sidebar (which is in essence just the Terminal plugin) to open claude code in my vault for certain operations like cleaning up properties or performing agentic tasks, such as reviewing my journal from past 7 days and writng me a executive summary. 

## Workspace Layout

Finally the workspace layout. 

On the left sidebar is the file explorer, with all the folders and active notes. The file explorer section will become the "search" panel when needed. 

Below, the section can be used for either backlinks or a calendar view to quickly navigate to a certain daily note. 

The editor is in the center. Today's daily note is pinned as the first tab. 

In the right sidebar are different tabs. 

First is a pinned Capture note. Then three plugins for AI — Copilot, Gemini, and Claude. Finally is the outline view.
